# C++ Tools

This repository contains memory and byte manipulation utility functions implemented in C++.

## Files

- **`bytes-tools.cpp`**: Endianness swapping and data extraction routines for 16-bit and 32-bit integers and IEEE 754 floating-point values from byte buffers.
- **`ram-tools.cpp`**: Windows process memory reading, memory region querying (`VirtualQueryEx`), pattern searching across process RAM, and hardware breakpoint thread management.

## Compilation & Usage

These utilities are targeted for Windows environment APIs (`windows.h`, `tlhelp32.h`).
